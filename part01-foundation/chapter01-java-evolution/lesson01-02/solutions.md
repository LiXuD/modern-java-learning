# 参考答案

选择题：1 B，2 C，3 B，4 C，5 B，6 C，7 B，8 C。

解释：OpenJDK 是上游项目；Oracle 两种构建并非同一授权产品；Classpath Exception 保护独立模块链接边界；21.0.13 的 OTN 转换由官方发布说明确认；其他发行版按自身许可；TCK 验证规范，不是性能或合规测试；免费使用不同于 SLA；替换需要业务回归。

## 思考题参考

1. 21.0.12 对应 NFTC，21.0.13 起的 Oracle JDK 更新转为 OTN（2026-10-20）。旧包原许可不因新更新自动改变，但冻结版本有安全风险。核对具体许可证、用途、已有 Oracle 合同与适用例外，普通企业生产若无授权可评估购买支持/许可、迁移到符合要求的 Temurin 21 等 GPL 构建，或在依赖兼容并测试后升级 Oracle JDK 25（当前 NFTC，关注未来期限）。不可把所有 Java 21 都视为收费。
2. 同主版本换发行商主要验证构建、补丁、配置和环境差异；8→21/25 同时引入字节码/API/强封装/GC/编码等变化。可先替换同主版本减少变量，也可在充分测试后一次迁移。至少测试功能/数据库驱动、TLS 和证书、反射/Agent、本地库、GC/资源与延迟、发布回滚。保留当前环境，先验证候选。
3. 独立业务代码使用适用 CPE 的库并不因此强制开源。分发 GPL JDK/定制运行时仍须遵守 GPL、版权告知、对应源码提供及第三方许可。NFTC 是有条件的无费许可，收费捆绑的再分发不能默认允许，需核对许可文本及单独协议。由法务根据具体包、分发方式和合同确认，不将教学判断替代正式审核。
