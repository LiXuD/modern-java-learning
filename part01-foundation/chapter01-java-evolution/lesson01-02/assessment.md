## 纠偏要点

1. Oracle JDK 21.0.13 起转入 OTN，普通企业内部生产如无适用许可通常须另行取得授权；旧 NFTC 包不会仅因新更新变更许可而自动失效，但冻结旧版本有安全风险。可更换到经验证的 Temurin/Corretto 21、获得适用 Oracle 授权，或评估主版本升级。个人使用、开发、符合条件的 Oracle 产品及 OCI 使用须按条款确认。业务源码公开与此内部生产升级无直接关系。
2. 同主版本发行版迁移仍需核验补丁、配置及发行商兼容性证明，实际回归功能、框架/JDBC 依赖、TLS/证书、Agent/JNI、JVM/GC、CPU/内存/延迟、稳定性与回滚等。不要将 TCK 当成业务回归。
3. GPLv2+CPE OpenJDK 可在履行适用 GPL 及第三方许可义务后随收费软件分发；核查对应源码提供方式及版权声明。独立业务代码不会仅因调用适用 CPE 的库而必须公开。NFTC 对未修改程序再分发的无费条件包括捆绑产品及相关服务的收费限制，不能直接将其运行时随收费软件分发；jlink 不改变许可证，具体镜像和合同须审核。实际商业交付由法务审查。

复核：[Oracle 21.0.13 发布说明](https://www.oracle.com/java/technologies/javase/21-0-13-relnotes.html)、[OTN 原文](https://www.oracle.com/downloads/licenses/javase-license1.html)、[NFTC 原文](https://www.oracle.com/downloads/licenses/no-fee-license.html)。GPLv2+CPE 参考第 1.2 节讲义及官方许可入口；本次 GNU 页面访问超时。此处为教学评价，不是企业法律意见。
