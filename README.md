# Modern Java Learning

《Java 8 到 Java 25：现代 Java 开发进阶》，扩展关注 JDK 26、27 及后续版本。

面向长期使用 JDK 8 的 Java 开发者。以 JDK 25 LTS 为主要学习环境、JDK 8 为对照基线，按照技术专题和 LTS 演进路线学习。
